# 参考图轨道

2026-10-31 按用户原始图片重做轨道可见截面：薄荷绿行进面、深青色内槽、浅绿隆起边沿、青绿色外坡与深青色侧壁。箭头为浅薄荷色。轨道面只有宽色块分段，边沿不再使用叠加的细圆管。

`ReferenceConveyor.Build` 沿已有 `NativeSpline` 生成同一组截面色带。独立场景与 `PlatformAssetBuilder` 共用这份几何生成代码。颜色写入网格，`ReferenceConveyor.shader` 保留明确分色，不受场景灯光影响；材质支持原有的 `_RouteClip` 入场揭示。曲线两侧、高低段与开口轨道都使用相同截面。

仅更换显示网格和轨道材质，未更改关卡控制点、原生样条采样、碰撞通道、投射逻辑、传送口位置或方块运动。平台资源重建直接复用既有 `*-collision.asset`，安装验证逐个比较其 SHA-256。新轨道每条只使用一个色带网格和一个箭头网格，预制体不含游戏脚本组件。

按用户此前要求，普通方块同时移除了矿石表面纹理采样，保留原有玩法配色与简单明暗；隐藏机制的外观不受此修改影响。

验证与实际关卡截图位于 `Design/MechanismUI/TrackApplied/`。验证在隔离 Unity 项目执行，完成后仅同步轨道生成资源、导入元数据与验证图片。没有重新打包 APK 或发布热更新。
