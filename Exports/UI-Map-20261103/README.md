# 当前游戏 UI 截图与位置标注

打开 index.html，选择界面，再点截图中的编号或右侧列表，查看 UI 区域对应的原图路径、图集切片位置、Hierarchy 对象路径和字体/代码来源。

- 仅含当前可正常进入或触发的 29 个页面，以及 1 张矿车完成标记状态展示。已排除旧商店、地区、排行、队伍、旧个人资料、活动/通行证等无入口页面和 GM 调试面板。
- icons.png：当前关卡矿车的完成勾号（Completed check）。完成标记图仅临时展示已有对象，没有改变完成状态或结算关卡。
- reference-ui.png：设置齿轮、礼包、撤回/打乱/传送带图标、道具数量圆牌，以及签到/道具弹窗中的对应图标。
- .png 是 Unity 实际渲染的 750×1650 原始截图；annotated/*.svg 是可单独打开的编号标注图，未修改截图像素。
- UI位置与源文件.csv：每个 UI 区域的完整源文件路径和位置；manifest.json：全部标注原始数据。
- 字体、遮罩、庆祝彩纸等不会伪标为 PNG；矿车、传送带、方块等 3D 场景也不当作 UI 贴图。
- 弹窗均调用游戏现有界面构建；未观看广告、领取奖励、删除用户数据或更改关卡完成记录。截图结束已恢复主页。

这些图片是用户此次要求的导出资料，不属于游戏运行资源；游戏源图仍在 Assets/LoopSort/Resources/LoopSort/Theme/。
